# Classification with two residual digits on an arbitrary prime graph

Codex (OpenAI), 27 November 2026. AI-authored written result for review.

Let each vertex be a prime coordinate $p$, with $p-2$ unary rows. Each edge of an arbitrary finite loopless multigraph $G$ contributes one row fixing the two endpoint digits. Parallel edges specify independent rows. Allow one extra singleton on all coordinates. Then the ordinary system misses a point for every assignment and attains a unique hole for some assignment **if and only if** the following holds in each connected component.

* After removing pendant trees, the remaining graph consists of three internally vertex-disjoint paths between the same two distinct vertices.
* At least one of the three paths is a single edge. Two or even three paths may be parallel single edges.

Every system meeting this criterion is indispensable after arbitrary reassignment. The test uses only the incidences of rows. Karve and Hirani proved the forbidden-topological-minor characterization for universal satisfiability in the simple binary graph case. We include the arguments needed here because existence of a *unique* satisfying tuple is an additional requirement and parallel rows occur for distinct dressed integer moduli. [Karve and Hirani](https://doi.org/10.1016/j.dam.2019.12.017)

## Necessity

Restrict each variable to two labels including its digit at the proposed unique hole. The unary rows can always be chosen to leave precisely a prescribed pair. If the original family has universal noncoverage, its binary edge system is satisfiable for all edge labels. At the one-hole assignment, removing any pendant tree preserves the unique-hole property on the remaining graph: regardless of its root digit, any binary labeling extends along a tree by choosing children successively. Conversely a singleton hole in a component is necessary for a global singleton, by independence of components.

A component with $v$ vertices needs at least $v+1$ edges for a unique solution. Relabel the solution all zero. For each of its $v$ single-bit flips a different edge row is required. Each such row prohibits a one and a zero. If these were all the rows, the all-one assignment would also survive.

Two edge-disjoint cycles in a connected component allow an unsatisfiable labeling. A cycle can force either value at a chosen vertex. Start in its unwanted value, propagate the forced successor value along the cycle, and forbid the last pair that would return to that start. This uses one row per edge and works on a two-edge cycle. For cycles meeting at a vertex force opposite values there. For vertex-disjoint cycles propagate incompatible forced values along a path between them whose interior avoids both cycles.

A subdivision of $K_4$ also allows an unsatisfiable labeling. In the edge order $01,02,03,12,13,23$ forbid respectively $00,00,10,11,01,01$. If vertex 0 is zero, vertices 1 and 2 must both be one, contradicting edge 12. If vertex 0 is one, vertex 3 must be one, hence vertices 1 and 2 must both be one, again a contradiction. To impose an endpoint exclusion along a longer path, use one row on each link to propagate its bad start to a forbidden finish. A path extends all other endpoint pairs, for instance by changing the forced label at the first or last link as needed. Only the implication on the excluded pair is needed for the unsatisfiability conclusion.

A connected graph of cycle rank at least two, with no two edge-disjoint cycles, contains a theta subgraph (three internally disjoint paths between two vertices). To see this start with a cycle and take a path outside its edges joining two distinct cycle vertices with interior off the cycle. Such a path exists unless all further cycles are edge-disjoint from the first. A path of one new parallel edge is allowed. The cycle's two arcs together with this path make a theta. If the whole component has any further cycle rank, it has either a cycle edge-disjoint from the theta or an additional path between two distinct theta vertices, using only new edges and with interior off the theta. This follows by contracting the connected theta to a point and lifting a cycle of the resulting multigraph. A path returning to the same theta vertex yields the edge-disjoint cycle case. If the two attachment points lie on the same theta branch, their segment with the new path is a cycle edge-disjoint from the cycle of the other two branches. This includes an attachment at either terminal by choosing the branch of the other point. If the attachments are internal to different branches, the new path completes a subdivision of $K_4$. Every case contradicts universal noncoverage. The component therefore has just the theta plus pendant trees.

Finally, if all three paths have interior vertices, consider its unique possible terminal pair $(a,b)$. Its interior continuation on each path must be unique by independence. The [separator inequality](cycles.md) implies that the pair differing at both terminals also extends on each of the three paths. These extensions combine to a second solution. Thus at least one branch must be a single edge.

## Sufficiency and deletion

Take one direct edge as the chord. Orient the other two paths around a cycle, forbid $(1,0)$ on these directed links, and forbid $(1,1)$ on the chord. The sole surviving core tuple is all zero. Forbid $(0,1)$ on pendant edges directed out from the core to force the rest to zero. A singleton now covers the whole grid.

Under arbitrary reassignment each theta branch excludes at most one terminal pair on any two surviving digits per vertex, by the [perfect-matching path estimate](cycles.md). Their intersection therefore leaves at least one pair. Deleting a core row leaves at least two terminal pairs because its damaged branch then extends all four pairs. Deleting a pendant edge detaches a tree whose root can take either value. In both cases there are at least two full tuples. After a unary deletion, choose two surviving labels at that vertex excluding the digit of a first solution, and find another solution on this new product. Deleting the singleton leaves an ordinary hole. These proofs also apply after arbitrary relabeling of every remaining row. [Conversion to genuinely distinct moduli](cycles.md)

## Consequences

There is exactly one extra ordinary row per component compared with $\sum_p(p-1)$, since the number of edges of each component exceeds its number of vertices by one. Thus at cap $X$ there are $O(\sqrt X/\log X)$ such extra rows, even allowing all graph shapes and parallel edges. Indeed there are only $\pi(\sqrt X)$ available primes by the prime-fibre necessity for irreducible covers. This counts the excess over the *actual* first-position budget. Ordinary higher prime positions can contribute further rows.

The reciprocal excess over the first-position harmonic allowance is bounded uniformly. Pool each pendant edge row with the $q-2$ unary rows of its child $q$. These $q-1$ distinct multiples have total mass at most $H_{q-1}/q$. On the core charge one cycle edge between $p,q$ by $(p^{-2}+q^{-2})/2$, since its modulus is at least $pq$. The cycle's charges are paid from the unary deficits $1/p^2$. Even a two-edge cycle spends at most these allowances. Each component has only one extra chord. Its mass is at most $(p^{-2}+q^{-2})/2$ and different components have disjoint terminals. The uniform bound for excess is therefore $\tfrac12\sum_p p^{-2}$ over all components. The four-prime construction in [cycles.md](cycles.md) has positive excess. In the full-period class closed under ordinary extensions, [transfer.md](transfer.md) gives a finite positive limiting additive improvement. A larger-order improvement requires moving beyond two residual labels with one binary constraint per edge, even if arbitrary graph topologies and repeated pairs are allowed.
